# СтудПлан

Учебный проект по дисциплине «Создание программного обеспечения». Это сайт, где студент может записывать задания по предметам и следить за сроками сдачи.

## Что можно делать

- Зарегистрироваться и войти в свой аккаунт.
- Добавлять предметы и задачи, редактировать и удалять их.
- Отмечать выполненные задания.
- Искать задачи и фильтровать список.
- Смотреть сроки в календаре и статистику выполнения.

На главной странице есть рекомендация, какую задачу сделать первой. Она рассчитывается по сроку сдачи, важности, сложности и примерному времени выполнения.

## На чём сделано

Интерфейс — React, Vite и Bootstrap. Сервер — Node.js и Express. Данные хранятся в PostgreSQL, работа с базой сделана через Prisma.

Основные папки:

- `client` — интерфейс сайта.
- `server` — сервер, база данных и тесты API.
- `tests/e2e` — тесты в браузере.

## Как запустить

Нужны Node.js 22.16+ и PostgreSQL 17. Команды ниже выполняются из корня проекта в PowerShell. Для Linux и macOS используйте `npm` вместо `npm.cmd`.

1. Установите зависимости:

   ```powershell
   npm.cmd install
   ```

2. Создайте в PostgreSQL базу `student_planner`. Это можно сделать через pgAdmin или SQL-командой:

   ```sql
   CREATE DATABASE student_planner;
   ```

   Для новой базы рекомендуется ICU `ru-RU`, чтобы поиск русских названий не зависел от системной локали:

   ```sql
   CREATE DATABASE student_planner TEMPLATE template0 LOCALE_PROVIDER icu ICU_LOCALE 'ru-RU';
   ```

   Это альтернативная команда создания, выполните только одну. Для уже существующей БД не удаляйте данные ради смены локали; подробности в DATABASE.md.

3. Скопируйте файл настроек:

   ```powershell
   Copy-Item server/.env.example server/.env
   ```

   В `server/.env` укажите свой пароль PostgreSQL в `DATABASE_URL`. Если в пароле есть специальные символы, их нужно URL-кодировать, например `@` заменить на `%40`.

   Для `JWT_SECRET` сгенерируйте случайную строку и вставьте её вместо значения из примера:

   ```powershell
   node -e "console.log(require('crypto').randomBytes(48).toString('base64'))"
   ```

4. Подготовьте базу и добавьте примеры задач:

   ```powershell
   npm.cmd run db:generate
   npm.cmd exec --workspace server -- prisma migrate deploy
   npm.cmd run seed
   ```

5. Запустите сервер:

   ```powershell
   npm.cmd run dev:server
   ```

6. Откройте второй терминал в корне проекта и запустите интерфейс:

   ```powershell
   npm.cmd run dev:client
   ```

Сайт будет доступен по адресу http://localhost:5173, сервер — http://localhost:3001.

Для проверки можно войти в готовый аккаунт: `demo@example.com`, пароль `demo12345`. Он создаётся командой `seed`.

## Запуск сервера через .bat (Windows)

После выполнения шагов 1–4 можно запускать проект двойным кликом по `start.bat` в корне проекта. PostgreSQL должен быть уже запущен.

Батник откроет три отдельных окна и выведет адреса в консоль:

- Фронтенд — http://localhost:5173.
- Бэкенд — http://localhost:3001 (порт берётся из `server/.env`).
- Prisma Studio, клиент базы данных — http://127.0.0.1:5555.

Дождитесь сообщения о запуске в каждом окне, затем открывайте адреса в браузере. Для остановки нажмите Ctrl+C в каждом окне сервиса.

## Полезные команды

- `npm.cmd run build` — собрать интерфейс.
- `npm.cmd test` — запустить тесты сервера (нужна настроенная база).
- `npm.cmd run db:studio` — открыть просмотр и редактирование базы по адресу http://127.0.0.1:5555.

Подробности проекта: [требования](REQUIREMENTS.md), [описание базы данных](DATABASE.md).

- [DEPLOY_GUIDE.md](DEPLOY_GUIDE.md) — пошаговый путь Windows → Ubuntu 24.04, Docker/Compose, проверка по IP, домен/HTTPS, SSH/UFW, логи, мониторинг, backup/restore и обновления.

Для Compose используется корневой `.env` по `.env.example`; локальному Node нужен `server/.env`. БД и backend наружу не публикуются. Prisma migrate deploy выполняет отдельный сервис; seed автоматически не запускается. На публичной базе не создавайте известный demo-аккаунт.
